# Agriculture Carbon Credit Analytics & Predictive Dashboard

## 📊 Project Overview

The **Agriculture Carbon Credit Analytics Dashboard** is an interactive **Power BI analytics and predictive analytics project** developed to analyze agriculture and carbon-credit-related data, identify trends, and generate future predictions.

The project combines **data analysis, Power BI visualization, and machine learning** to transform historical data into actionable insights and future projections.

## 🎯 Objectives

* Analyze historical agriculture and carbon-credit-related data.
* Develop an interactive Power BI dashboard for business reporting.
* Track important metrics using KPIs and visualizations.
* Identify trends and patterns in historical data.
* Apply machine learning for predictive analysis.
* Generate future data using the trained predictive model.
* Analyze predicted values to support future-oriented decision-making.

### Predictive Analytics

A **Random Forest Regressor** was developed to predict future values based on historical data.

The workflow included:

1. Data preprocessing
2. Feature preparation
3. Train-test splitting
4. Random Forest Regressor model training
5. Model prediction
6. Model evaluation
7. Future data generation
8. Analysis of predicted future values
9. Visualization of predictive results

## 🤖 Machine Learning Model

**Algorithm:** Random Forest Regressor

### Model Performance

| Metric   |  Score |
| -------- | -----: |
| MAE      | 0.3225 |
| MSE      | 0.1935 |
| R² Score | 0.9968 |

The model achieved an **R² score of approximately 0.997**, indicating a strong fit on the evaluation dataset.

> Note: Model performance depends on the dataset, feature selection, train-test split, and preprocessing methodology.

## 🔮 Future Data Prediction

After training and evaluating the Random Forest Regressor, the model was used to **generate future data/predictions**.

The predicted future data was then analyzed to:

* Identify expected trends
* Compare historical and predicted values
* Understand future patterns
* Generate analytical insights
* Support data-driven decision-making
